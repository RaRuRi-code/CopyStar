Запуск проекта

1
Перейдите в директорию проекта
cd django_project
2
Создайте виртуальное окружение
# Linux/macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
3
Установите зависимости
pip install -r requirements.txt
4
Выполните миграции
python manage.py migrate
5
Заполните базу данных товарами
python manage.py shell < populate_db.py
6
Создайте суперпользователя
python manage.py createsuperuser
7
Запустите сервер
python manage.py runserver
После запуска
Сайт:
http://127.0.0.1:8000
Админ-панель:
http://127.0.0.1:8000/admin

🔌 AJAX API Endpoints
POST /api/cart/add/ Добавить в корзину
POST /api/cart/remove/ Удалить из корзины
POST /api/cart/update/ Обновить количество
GET /api/cart/detail/ Содержимое корзины
POST /api/order/create/ Создать заказ
GET /api/search/ Поиск с подсказками
GET /api/product/<slug>/reviews/ Отзывы товара
POST /api/review/add/ Добавить отзыв
